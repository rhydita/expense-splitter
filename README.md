# Split — Expense Splitter Prototype

## How to run this on your computer

1. Make sure Node.js is installed (download from nodejs.org if not — LTS version)
2. Open a terminal in this folder
3. Run: `npm install`
4. Run: `npm run dev`
5. Open the link it shows in your browser (usually http://localhost:5173)

## How to push to GitHub

1. Create a new empty repository on github.com (don't add a README there)
2. In this folder's terminal, run:
```
git init
git add .
git commit -m "Expense splitter prototype"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```
